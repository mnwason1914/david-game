# 다윗 1장 MVP (Three.js 웹)

폰 브라우저에서 바로 실행되는 로우폴리 3인칭(캐릭터 뒤 시점) 액션 MVP입니다. 엔진은 Three.js 0.160 (vendor 폴더에 포함, 외부 서버 불필요).

## 실행
- PC: 이 폴더에서 `npx http-server -p 8123` 실행 후 http://localhost:8123 접속 (파일을 더블클릭하면 모듈 보안 때문에 안 열림)
- 주소 뒤에 `?scene=6` 처럼 붙이면 해당 장면부터 시작 (1 씬1 · 2 밤도둑 · 3 하얀귀 · 4 수금 · 5 자유 시간(서브 퀘스트) · 6 물매 만들기 · 7 출정 · 8 곰 · 9 사자 · 10 엔딩)

## 모델 교체 (Tripo/블렌더 → glb)
`js/data/models.js`의 슬롯에 `glb: 'assets/david.glb'`를 넣고, 사람형이면 `boneMap`에 관절 이름을 연결합니다
(hips, spine, head, armL, armR, legL, legR). 무기는 오른손 소켓(handR)에 붙습니다. glb 로드에 실패하면 지금의 절차적 모델로 자동 대체됩니다.
※ 사람형 glb는 현재 '관절 회전' 방식 애니메이션만 연결되어 있습니다. glb에 들어 있는 애니메이션 클립 재생은 아직 없습니다.

## 조작
모바일: 왼쪽 화면 끌기 = 이동, 오른쪽 화면 끌기 = 시점 회전(타깃 고정 중에는 좌우로 튕겨 대상 바꾸기), 약공격(최대 2연타), 강공격(전방 찌르기), 방패(누르고 있으면 방어 · 맞기 직전에 누르면 저스트 가드), 스텝(조이스틱 방향, 안 밀면 뒤로), 타깃 고정, 떡(회복), 상호작용 버튼. 방어를 누른 채 엄지를 공격 버튼으로 밀어도 됨
PC: WASD 이동 · 마우스 끌기 또는 Z/C 시점 회전 · J/스페이스 약공격 · U 강공격 · L 방어 · K/Shift 스텝 · O 타깃 고정 · E 상호작용/대사 넘기기 · Q 떡 · 수금은 1/2/3

## 지팡이 전투 (설계서: ../staff-combat/지팡이-전투-설계서.html)
- 스태미나(체력바 아래 금색 막대): 약공격 12/14, 강공격 30, 스텝 20(연속이면 +8씩), 방어는 적 공격마다 다름. 0이 되면 1.2초 탈진
- 방어로 막으면 피해의 25%가 체력바에서 깎임. 스태미나가 모자라면 가드 붕괴(피해 50% + 0.9초 경직)
- 곰 돌진·일어서 내리찍기, 사자 돌진·덮치기는 방어 불가(붉은 표식 + 울림 + 화면 가장자리 붉게). 스텝 무적(0.18초)으로 피함
- 적 자세: 보스 체력바 아래 막대. 가득 차면 붕괴 → 강공격으로 결정타(피해 ×3). 도둑은 붕괴 뒤 강공격으로 제압
- 검수 스크립트: tools/combat-test.js + tools/combat-checks.js(장면 2), tools/boss-checks.js(장면 7·8)

## 레벨과 서브 퀘스트
- 숫자 조정: `js/data/progression.js` (필요 경험치, 레벨당 공격력 +8%, 하트가 느는 레벨 3·5·7·9, 보상 경험치)
- 경험치: 도둑 15 · 곰 120 · 사자 160 · 본편 씬 완료 40 · 서브 퀘스트 완료 50
- 서브 퀘스트 (5번 자유 시간에서 진행)
  - C 형들의 점심: 이새 메뉴 → 엘리압에게 도시락 전달 → 가죽 허리띠 (큰 피해 1 감소)
  - D 우물가 노파의 물동이: 우물가 여인 → 덤불 속 물동이 → 우물 → 집까지 → 무화과 +3
  - E 다친 양 치료: 우리 옆 다친 양 → 우슬초 3개 + 창고 기름 → 무화과 회복량 +2
  - F 무화과 따기: 이새 메뉴 → 언덕 무화과나무를 지팡이로 쳐서 10개 → 무화과 +4
  - B 물매 만들기 (6번, 곰과 사자 전 필수): 이새 → 창고 가죽 조각 → 염소 우리 염소털 끈 → 시냇가 매끄러운 돌 5개 → 나무 과녁 3회 → 물매 해금 (R 키 / 물매 버튼)
- 물매는 투척 아이템: 아래 무화과떡 옆 칸(숫자 = 남은 물맷돌, PC는 R). 던질 때마다 돌 1개. 만들 때 5개로 시작, 최대 10개. 바닥의 빛나는 돌 자리(시냇가, 곰·사자 경기장)에서 2개씩 다시 줍고 자리는 잠시 뒤 다시 생김
- 물매 전투: 곰전 1단계는 물매로 곰 머리를 3번 맞혀야 양을 놓음. 사자는 가끔 바위 위로 올라가 덮칠 준비를 하는데, 물매로 맞히면 떨어져 기절. 숫자는 `js/data/weapons.js`의 sling
- 밤도둑은 한 명(양을 안고 달아나는 두목)

## 적 공격 패턴: 큰 공격 → 빈틈
- 모든 적은 예고(바닥 표시) 뒤 크게 한 방 들어오고, 그 뒤 2초 멈춘다(노란 원). 이때 맞혀야 유효타(피해 1.6배). 그 밖에는 거의 막힘(0.1배)
- 도둑: 몽둥이 크게 내리치기만 씀 · 곰: 일어서서 내리찍기(바위 돌진 기절도 빈틈) · 사자: 덮치기(바위에서 물매로 떨어뜨려도 빈틈)
- 저스트 가드로 휘청이게 하거나 자세를 무너뜨려도 빈틈으로 침
- 숫자: `js/data/enemies.js` 의 opening(빈틈 시간), COMBAT.openMult / guardedMult. 곰·사자 체력 50 → 36
